# design-report — дизайн бөлімінің апталық есебін автоматтандыру

YouGile-ден жабылған тапсырмаларды оқиды, файлдарды санайды, ережелер бойынша пост/карусель/обложка т.б. есептейді,
Telegram арқылы дизайнерлерге тексертеді және сейсенбі 10:00-де Excel-ді басшыға жібереді.
YouGile-де ештеңе өзгертпейді (тек оқиды).

## Кесте (Алматы уақыты)
| Уақыт | Не болады |
| --- | --- |
| әр 15 мин | YouGile sync; файлсыз жабылған тапсырма мен «түзету ме, қосымша ма» сұрақтары дизайнерге |
| дс 08:00 | өткен аптаның барлық чатын соңғы рет қайта оқу |
| дс 09:00 | әр дизайнерге апталық есеп: [Толығырақ] [Қате бар] [Бәрі дұрыс]; админге жиынтық |
| сс 10:00 | Excel басшыға, апта жабылады (кейінгі өзгерістер келесі аптаға «қосымша») |

## Telegram командалары (админ)
`/weekly` жиынтық · `/review` тексеру кезегі · `/export` Excel · `/send_boss` басшыға қолмен жіберу ·
`/close_week 2026-09-21` аптаны жіберусіз жабу · `/code Асылжан` дизайнерге тіркеу сілтемесі ·
`/code басшы Темірлан` басшыға сілтеме · `/people` · `/sync`
Күнді көрсетуге болады: `/export 2026-09-21`

Админ әрі дизайнер бола алады: админ `/code ӨЗ_АТЫ` сілтемесін өзі басса, екі рөл біріктіріледі.

## Қызметкерлерді тіркеу
Telegram ботқа адамға бірінші болып жазуға рұқсат бермейді, сондықтан шақыру сілтеме арқылы жүреді:
1. `/user Жания @zhaniya_k` — әр қызметкердің username-ін енгізу (басшыға: `/user басшы Темірлан @username`).
2. `/invite` — шақыру хабарламасын топқа жіберу (немесе ботты топқа қосып, сол жерде `/invite`).
3. Қызметкер «🚀 Ботқа тіркелу» → Start басады: username сәйкес келсе — бірден тіркеледі,
   сәйкес келмесе — админге «Бұл кім?» деген сұрау келеді, бір батырмамен растайсыз.
Жеке сілтеме керек болса: `/code Жания`.

## Mini App (Telegram ішіндегі қосымша)
Railway → design-report → Settings → Networking → **Generate Domain** (порт: Railway өзі береді).
Variables: `WEBAPP_URL=https://<домен>.up.railway.app`. Бот мәзір батырмасын «📱 Есеп» етіп өзі қояды.
Қосымшада: апта таңдау, «бояу үлгісі» карточкалары (өткен аптамен салыстыру), пәндер, тапсырмалар,
8 апталық динамика графигі, ашық тапсырмалар/дедлайндар. Дизайнер — тек өзін, админ/басшы — барлығын көреді.
Әр сұраныс Telegram initData қолтаңбасымен тексеріледі.

## Сурет-карточка
Апталық есеп дизайнерге сурет-карточка + мәтін болып келеді (қаріп: PT Sans, `assets/fonts`).

## Google Sheets (тірі кесте)
Railway Variables: `GOOGLE_SHEET_ID` (кесте сілтемесіндегі /d/ мен /edit арасындағы бөлік) және
`GOOGLE_SERVICE_ACCOUNT_JSON` (сервис-аккаунт кілті: JSON немесе base64). Кестені сервис-аккаунттың email-імен Editor ретінде бөлісу керек.
Әр аптаға бір парақ; ашық апталар әр синхронизациядан кейін, өзгеріс болса ғана жаңартылады. Қолмен: `/sheet`.

## Толық емес ТЗ ескертуі
Соңғы 24 сағатта берілген тапсырмада дедлайн жоқ болса немесе ешбір ереже сәйкес келмесе, админге бір рет хабар келеді.

## Хабарлама жіберу
Админ мен басшы `/msg` арқылы бір немесе бірнеше қызметкерге (немесе барлығына) мәтін, фото, файл, дауыс жібере алады.
Қызметкер «↩️ Жауап беру» батырмасы арқылы жауап береді. Болдырмау: `/cancel`.

## AI-сұрақтар (міндетті емес)
Railway Variables-ке `GEMINI_API_KEY` (тегін, aistudio.google.com) немесе `OPENAI_API_KEY` қосылса, кез келген мәтінге бот жүйедегі деректер бойынша жауап береді.
Дизайнерге тек өз деректері, админге — барлығы. Күніне 30 сұрақ (`AI_DAILY_LIMIT`). Модель `AI_MODEL` (әдепкі: Gemini — `gemini-3.5-flash-lite`, OpenAI — `gpt-5-mini`).
Gemini тегін тарифінде деректер Google өнімдерін жақсартуға пайдаланылуы мүмкін.

## Railway-ге орналастыру (бір рет)
1. railway.app → **New Project** → **Deploy PostgreSQL**.
2. Компьютерде, осы папкада:
   ```
   npm install -g @railway/cli
   railway login
   railway link          # жаңа жобаны таңдаңыз
   railway add --service design-report
   railway up --service design-report
   ```
3. Railway-де design-report сервисі → **Variables** → мыналарды қосыңыз:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `YOUGILE_API_KEY`, `TELEGRAM_BOT_TOKEN` — `.env` файлынан
   - `ADMIN_SETUP_CODE` — өзіңіз ойлап тапқан құпия сөз
   - `REPORT_MONTH1` — «1-АЙ» басталған күн (қаласаңыз)
4. Ботқа `/start <ADMIN_SETUP_CODE>` жазыңыз → сіз админсіз.
5. `/code` арқылы әр дизайнерге және басшыға тіркеу сілтемесін жіберіңіз.

Сервис бір данада (1 replica) жұмыс істеуі керек.

## Айлық мақсаттар
Кесте логикасы «DESIGN | АЙЛЫҚ МАҚСАТТАР 2026-2027»-пен бірдей: Операционный / Стратегиялық мақсаттар,
Конверсия = Факт ÷ Мақсат (100%-дан аспайды), бөлім = орташа, Ортақ көрсеткіш = екі бөлімнің орташасы.
- Дизайнер: «🎯 Мақсаттарым» → мақсат қосу (әр жолға бір; мәні 100%-дан басқа болса «| 95%» немесе «| 3»), өткен айдан көшіру, өзгерту/өшіру.
- Сенбі 19:00 — бот «🌙 Апта аяқталды! Айлық мақсатыңды толтыр» деп мақсаттар тізімін жібереді: әр мақсат — жеке батырма.
  Басқанда 0 / 25 / 50 / 75 / 100% жылдам батырмалары шығады немесе санды өзі жазады; толтырылғаны ✔ белгіленеді.
  «✅ Дайын» → жалпы айлық мақсат конверсиясы % (операционный / стратегиялық, орындалғаны N/M), сосын ұнаған жұмыстар (3 суретке дейін) және апта қорытындысы.
- Дүйсенбі 08:00 — толтырмағандарға «☀️ Қайырлы таң» ескертуі. Дүйсенбі 12:00-ге дейін жазылғаны өткен аптаға кіреді.
- Айдың алғашқы екі дүйсенбісі 10:00 — мақсаты жоқтарға еске салу.
- Апталық есепке «🎯 Айлық мақсат конверсиясы» жолы қосылады; Excel-де 5 жаңа парақ:
  АЙЛЫҚ МАҚСАТ · АЙЛЫҚ МАҚСАТ % · МАҚСАТ КОНВЕРСИЯСЫ · ОРЫНДАЛҒАН МАҚСАТТАР · ҰНАҒАН ЖҰМЫСТАР (суреттерімен).
- Кестеден автоматты: бот іске қосылғанда және әр дүйсенбі 09:30 «DESIGN БӨЛІМІ | Айлық мақсат конверсиясы» кестесін (GOALS_SHEET_ID) өзі жүктеп, ботта мақсаты жоқ дизайнерлерге осы айдың мақсаттары мен фактілерін салады. Қолмен: `/import_goals` (файлсыз). Кесте «сілтемесі барлар — оқу» болуы керек.
- Админ: `/goals_team` — бөлім жиынтығы; Google Sheets-ті xlsx етіп жүктеп, ботқа «/import_goals» қолтаңбасымен жіберу —
  осы айдың мақсаттары (және фактілері) әр дизайнерге өзі түседі (парақ аты тегінен басталуы керек). Ай: «/import_goals 2026-10».

## Figma апталық есебі («ЕСЕП | DSGN»)
- Сенбі ағынының соңында бот «📝 Апта қорытындысы» сұрайды (Мәселе / Шешімі / Жетістік / Ұсыныс).
- Дүйсенбі 12:00 бот өткен аптаның деректерін GitHub-тың `reports` бұтағына салады: `weeks/<дүйсенбі>/data.json` + ұнаған жұмыстардың суреттері. Қолмен: `/export_figma [YYYY-MM-DD]`.
- Claude-тың жоспарлы тапсырмасы (дүйсенбі ~12:26) «ЕСЕП | DSGN» файлында «4 ай 2 апта» сияқты бет ашып, «ШАБЛОН · Апталық есеп» бетіндегі
  6 слайдты әр дизайнерге толтырады: Титул · Атқарылған жұмыстар · ТОП-3 ұнаған жұмыс · Апта қорытындысы · Айлық мақсаттар · Конверсия.
  Генератор: `scripts/figma-week.js`, бөліктерге бөлу: `node scripts/figma-batches.mjs data.json hashes.json out/`.
  Дизайнерлердің қолмен жасаған слайдтары өшірілмейді — генератор тек өз слайдтарын жаңартады.
- Шаблонды өзгерту: «ШАБЛОН · Апталық есеп» бетіндегі дизайнды еркін өзгертуге болады, тек `{…}` атаулы мәтін қабаттарының,
  `liked-1..3`, `goals`/`goal-row`, `g-bar`, `ring` атауларын сақтаңыз.
